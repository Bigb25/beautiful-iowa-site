Beautiful Iowa — Privacy Policy

Last updated: October 23, 2026

Who we are

Beautiful Iowa (beautifuliowa.org) is the website of the Beautiful Iowa YouTube channel (@BeautifulIowa), run from Jasper County, Iowa. Contact: b.dealwatch@gmail.com.

This website

This is a simple informational website. It does not collect personal information, does not run analytics or advertising trackers, and does not set cookies. The site is hosted on GitHub Pages; GitHub may log visitor IP addresses for security purposes as described in GitHub's own privacy statement.

Our use of YouTube API Services

The channel's operator uses software that connects to the YouTube API Services to manage the Beautiful Iowa channel itself: reading the channel's own statistics and, in the future, uploading and publishing the channel's own videos. This access is authorized by the channel owner through Google OAuth.

Specifically, the software stores an OAuth refresh token, provided by the channel owner, in a secured file accessible only to the operator. It uses that token solely to act on the Beautiful Iowa channel. It does not access any other person's YouTube account or data, does not collect data about viewers or other users, and does not share any data with third parties.

By using YouTube, users are bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. The channel owner may revoke this software's access at any time through Google Account security settings (third-party access).

Changes

If this policy changes, the updated version will be posted on this page with a new date.
